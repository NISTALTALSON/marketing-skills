# Marketing Skills

A curated collection of marketing, growth, startup, branding, content, SEO, social, launch, and founder skills.

## Contents

- `local/agents`: marketing-focused agents found in the Desktop `resource` collection.
- `local/references`: startup and marketing reference documents found at the root of `resource`.
- `local/skills`: every matching skill directory discovered recursively under `resource/skills`, preserving its original relative path.
- `online/coreyhaines31-marketingskills`: downloaded from https://github.com/coreyhaines31/marketingskills.
- `online/Jakeschincariol-founder-skill`: downloaded from https://github.com/Jakeschincariol/founder-skill.

The online folders are included as downloaded snapshots without their nested Git metadata so this collection can be versioned as one repository.
